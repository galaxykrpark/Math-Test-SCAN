        2-1 채점 점수

        시험지 사진을 찍고 'AI로 점수 계산'을 누르면 채점 결과가 여기에 나타나요.

        2-2 상세 설명

        채점이 끝나면 자세한 설명이 여기에 나타나요.

        2-3 보충 문제

        점수가 낮은 유형(70% 미만)을 골라 두었어요. 문제 수를 고르고 보충 문제 만들기를 누르세요.

        채점이 끝나면 보충할 유형이 여기에 나타나요.

        3 채점 결과 제출

        채점 점수, 유형별 점수, 상세 설명과 (만들었다면) 보충 문제를 PDF 파일 하나로 만들어요.

        위 두 버튼은 순서가 없어요. 둘 중 하나만 누르세요. 먼저 보내기를 눌러 보고, 안 되면 저장 후 내 파일에서 직접 공유하세요.

        채점이 끝나면 누를 수 있어요.
