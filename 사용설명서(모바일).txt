==============================================
  onemath2 모바일 - AI 수학 시험지 채점 (스마트폰 앱, AI 앱 자동 연동판)
==============================================

스마트폰 카메라로 학생 시험지와 답안지를 찍으면,
폰에 있는 ChatGPT · 제미나이 · Claude 로 채점해서
총점, 유형별 점수, 틀린 이유, 보충 문제를 보여 주고 PDF 문서로 보내 줍니다.
PC 프로그램(bat, 파이썬)이 없어도 폰 혼자 동작합니다.


■ 1. 처음 한 번만: 앱을 인터넷에 올리기
----------------------------------------------
폰에서 카메라를 쓰고 홈 화면에 설치하려면 https 주소가 필요합니다.
이 mobile 폴더를 무료 웹 호스팅에 올리면 됩니다. (둘 중 하나)

[가장 쉬움] Netlify Drop
  1) PC에서 https://app.netlify.com/drop 에 들어가 무료 가입(구글 계정 가능)합니다.
  2) 이 mobile 폴더를 통째로 화면에 끌어다 놓습니다.
  3) 잠깐 뒤 https://○○○.netlify.app 주소가 나옵니다. 이 주소를 폰으로 보내 두세요.
  ※ 화면 파일을 고친 뒤에는 같은 사이트의 [Deploys] 에 폴더를 다시 끌어다 놓으면 됩니다.

[GitHub 를 쓴다면] GitHub Pages
  저장소에 mobile 폴더 안의 파일들을 올리고 Settings → Pages 에서 켜면
  https://아이디.github.io/저장소이름/ 주소가 생깁니다.

※ 올라가는 것은 화면 파일뿐입니다. 시험지 사진, 채점 결과, API 키는 서버에 저장되지 않고
  각자의 폰 안에만 남습니다.


■ 2. 폰에 설치하기
----------------------------------------------
- 안드로이드(크롬): 주소를 열고 오른쪽 위 ⋮ → [홈 화면에 추가] 또는 [앱 설치]
- 아이폰(사파리):   주소를 열고 아래 공유 버튼 □↑ → [홈 화면에 추가]
홈 화면의 onemath2 아이콘을 누르면 앱처럼 전체 화면으로 열립니다.


■ 3. 채점할 AI 고르기 (맨 위 'AI' 칸)
----------------------------------------------
ChatGPT / 제미나이 / Claude 중 하나를 누르고, 연결 방식을 고릅니다.

(1) 📲 내 폰의 AI 앱으로 자동 보내기  (키 필요 없음, 구독 중인 앱 그대로 사용)
    - 폰에 그 AI 앱이 설치되어 있고 로그인되어 있어야 합니다.
    - [AI로 점수계산] 한 번에 사진과 지시문(채점 점수·유형별 점수·상세 설명 요청)이
      공유 창으로 넘어가고, AI 답을 복사해서 돌아오면 onemath2 가 자동으로 읽어 채점합니다.
    - 휴대폰 보안 정책상 웹 앱이 AI 앱의 [전송] 버튼을 대신 누르거나 AI 앱 화면을 읽을 수는
      없습니다. 그래서 공유 창에서 AI 앱 고르기, AI 앱에서 [전송], 답 [복사] 는 직접 눌러야 합니다.
      손을 전혀 대지 않는 완전 자동은 (2) API 키 방식입니다.

(2) 🔑 API 키로 자동 채점  (버튼 한 번으로 끝)
    - 고른 AI 회사의 API 키를 한 번 넣으면 이 앱 안에서 바로 채점합니다.
    - 키 받는 곳 (칸 아래 '키 받는 곳' 링크와 같습니다)
        ChatGPT : https://platform.openai.com/api-keys   (유료, 사용한 만큼)
        제미나이 : https://aistudio.google.com/apikey      (무료 등급 있음)
        Claude  : https://platform.claude.com/settings/keys (유료, 사용한 만큼)
    - 키는 이 폰의 앱 저장 공간에만 저장되고, 고른 AI 회사로만 보내집니다.
      폰을 다른 사람과 같이 쓴다면 앱으로 보내기 방식을 쓰세요.
    ※ ChatGPT Plus·Gemini Advanced·Claude Pro 같은 '앱 구독'과 'API 키'는 별개입니다.
      구독만 있다면 (1) 앱으로 보내기를 쓰면 됩니다.


■ 4. 사용 순서
----------------------------------------------
1) 학생 정보: 학원명(기본값: 양덕롯데캐슬교실), 학생 이름, 선생님 이름, 주제학습 단원명을 입력합니다.
2) 사진 찍기:
   - [📝 학생 시험지] 칸의 📷 사진 찍기 → 카메라가 열리면 찍고 [확인]. 한 장씩 들어갑니다.
     여러 장이면 📷 를 다시 눌러 계속 찍으세요. (최대 10장)
   - [✅ 답안지] 칸도 같은 방법으로 정답지를 찍습니다. (선택)
   - 이미 찍어 둔 사진은 🖼️ 앨범 으로 여러 장을 한꺼번에 고를 수 있어요.
   - 잘못 찍은 사진은 사진 오른쪽 위 ✕ 로 지웁니다.
3) [🤖 AI로 점수계산] 을 누릅니다.
   ▶ API 키 방식: 1~2분 기다리면 2-1 에 점수가 나옵니다.
   ▶ 앱으로 자동 보내기 방식: 누르는 즉시 공유 창이 뜹니다.
      ① 공유 목록에서 ChatGPT(또는 Gemini, Claude) 앱을 고르고 앱에서 [전송] 을 누릅니다.
         지시문은 복사도 되어 있어서, 앱 입력칸에 글이 안 들어갔으면 길게 눌러 [붙여넣기] 하세요.
         (공유 창을 닫았거나 안 떴으면 안내 칸의 [📤 다시 보내기])
      ② AI 답이 다 나오면 코드 칸의 [복사] 버튼(또는 답을 길게 눌러 복사)을 누릅니다.
      ③ onemath2 로 돌아오기만 하면 클립보드의 답을 자동으로 읽어 바로 점수가 나옵니다.
         - 안드로이드: 처음 한 번 '클립보드 보기' 권한을 물으면 [허용] 을 눌러 주세요.
         - 아이폰: 자동 읽기가 막혀 있어서 [📋 AI 답 붙여넣기] → [붙여넣기] 를 눌러 주세요.
         - 제미나이: 앱 화면 위에 작은 창으로 떠서 열렸다면, 답을 복사하고 제미나이 창을 닫은 뒤
           onemath2 화면을 한 번 톡 눌러 주세요. 그때 자동으로 읽습니다.
         - 다른 방법(안드로이드, 홈 화면에 설치한 경우): AI 답 글을 길게 눌러 선택 → [공유]
           → onemath2 를 고르면 앱이 열리면서 바로 반영됩니다.
      ※ AI 앱에 다녀오는 사이 앱이 새로 열려도 사진·학생 정보·기다리던 요청이 그대로 이어집니다.
         다음 학생을 할 때는 1단계의 [🔄 새 학생 시작] 을 누르세요.
4) 2-1 채점 점수 / 2-2 상세 설명 을 확인합니다.
   "👀 선생님 확인이 필요한 문항" 이 보이면 시험지를 직접 보고 판단해 주세요.
5) 2-3 보충 문제: 70% 미만 유형이 미리 체크되어 있어요. 문제 수를 고르고
   [보충 문제 만들기] 를 누릅니다. (앱으로 보내기 방식이면 3)과 같은 순서)
6) 3 채점 결과 제출:
   - [📤 PDF 보내기] → 카카오톡, 메일, 드라이브 등으로 PDF 파일을 바로 보냅니다.
   - [💾 폰에 PDF 저장] → 다운로드 폴더(아이폰은 '파일' 앱)에 저장합니다.
   문서에는 총점, 유형별 점수, 확인 필요 문항, 채점 기준, 맞은/틀린 번호, 틀린 이유,
   보완 포인트, 문항별 결과표, (만들었다면) 보충 문제와 정답·풀이가 들어갑니다.


■ 5. 이럴 땐 이렇게
----------------------------------------------
- 공유 목록에 AI 앱이 안 보여요
    → 목록 끝의 [더보기]/[편집]에서 찾아 보세요. 그래도 없으면 [💾 사진 저장] 과
      [📋 지시문 복사] 를 누른 뒤 [↗ 앱 열기] 로 AI 앱을 열어 사진과 글을 직접 넣으세요.
- "결과(JSON)를 찾지 못했어요" / "답이 중간에 끊겼어요"
    → AI 답 전체가 복사되지 않은 경우입니다. AI 앱에서 "JSON을 처음부터 끝까지 다시 써 줘"
      라고 보낸 뒤 코드 칸의 복사 버튼으로 다시 복사하세요.
- "API 키가 맞지 않아요" → 키를 다시 복사해 넣으세요. 앞뒤 띄어쓰기가 없어야 합니다.
- "사용량이 넘쳤어요" → 무료 사용량을 넘었거나 결제가 필요한 상태입니다. 잠시 뒤 다시 하거나
  앱으로 보내기 방식을 쓰세요.
- 사진은 글씨가 잘 보이게 밝은 곳에서, 시험지 한 장이 화면에 꽉 차게 찍어 주세요.
- 시험지에 학생 실명이 보이면 가리고 찍거나, 학생 이름 칸에 가명을 쓰는 것을 권합니다.
  (사진은 고른 AI 회사로 보내집니다)

  폰이 새 화면을 받습니다.


■ 다른 컴퓨터(예: 집 PC)에서 이어서 고치기·디버깅하기
----------------------------------------------
폴더를 USB 등으로 통째로 복사하지 말고, GitHub 저장소에서 받아서 작업하세요.
그래야 고친 내용을 GitHub 에 올리고(push), 다른 컴퓨터에서 받아(pull) 계속 이어 갈 수 있습니다.
(mobile2 폴더는 GitHub 와 연결되어 있지 않은 복사본입니다. 같은 내용이 이 mobile 저장소에 들어 있습니다)

저장소 주소: https://github.com/galaxykrpark/Math-Test-SCAN

[처음 한 번만] 그 컴퓨터에 준비하기
  1) Git 설치: https://git-scm.com 에서 받아 설치합니다.
  2) Claude Code 설치 후 로그인합니다.
  3) 원하는 위치에서 터미널을 열고 저장소를 받습니다.
       git clone https://github.com/galaxykrpark/Math-Test-SCAN
     → Math-Test-SCAN 폴더가 생깁니다. (회사 PC의 mobile 폴더와 같은 내용)
  4) 처음 push 할 때 GitHub 로그인 창이 뜨면 galaxykrpark 계정으로 로그인합니다.

[작업할 때마다] 순서
  1) 시작 전에 최신 내용 받기:   git pull
  2) Claude Code 로 Math-Test-SCAN 폴더를 열고 고치기·디버깅을 합니다.
  3) 끝나면 GitHub 에 올리기:    Claude Code 에 "커밋하고 push 해 줘" 라고 하거나
       git add -A
       git commit -m "무엇을 고쳤는지"
       git push
  4) 다른 컴퓨터로 돌아가면 다시 1) git pull 부터 합니다.
  ※ 두 컴퓨터에서 동시에 고치고 pull 없이 push 하면 충돌이 날 수 있으니,
    항상 "pull → 작업 → push" 순서를 지키세요.

[알아 둘 점] Claude Code 대화 기록은 이어지지 않습니다
  - Claude Code 의 대화 기록은 폴더 안이 아니라 각 컴퓨터의 사용자 폴더(.claude)에 저장됩니다.
    그래서 다른 컴퓨터에서 열면 코드는 그대로지만, 이전 대화는 모르는 상태로 시작합니다.
  - 이어서 시킬 때는 무엇을 하고 있었는지 한두 줄로 알려 주세요.
    예) "AI 앱 자동 받기(클립보드 자동 읽기)를 실제 안드로이드 폰에서 확인하다가 ○○ 문제가 났어"
  - 코드 구조와 설계 이유는 이 설명서와 각 파일 맨 위 설명에 적혀 있어서,
    Claude Code 가 파일을 읽으면 대부분 이어서 작업할 수 있습니다.

[화면을 PC에서 확인하기]
  - 카메라·공유 기능은 https 주소의 폰에서만 제대로 됩니다. 고친 뒤에는 push 하고
    Netlify 에 다시 올려(또는 자동 배포) 폰으로 확인하세요.
